# FIN 3313 · Financial Management — Reference

A single-page reference site for **FIN 3313 Financial Management** (Texas State University, Fall 2026), built on Berk, DeMarzo & Harford, *Fundamentals of Corporate Finance*, 6e.

**Live site:** https://yogfity.github.io/fin3313-financial-management/

## What's inside

- **Seven chapters** — stock valuation, risk and return, systematic risk and the CAPM, cost of capital, raising equity, debt financing, capital structure.
- **70 worked problems** in a consistent format: problem → given → steps → answer → TI-84 keystrokes → the trap the question is built to catch. Every answer was re-derived independently, and the Exam 2 problems were checked against the answer key.
- **Formula tables** with a "when to use" column — click a row to copy the expression.
- **Project: estimating Coca-Cola's beta** — 60 months of KO, SPY, and T-bill returns regressed in Python (`yfinance` + `statsmodels`). β ≈ 0.34.
- **Practice set**, the one-page **formula sheet** from the final, and a **TI-84 reference** translating the BA II Plus workflow.
- ⌘K search across every problem and formula.

## Stack

Plain HTML, CSS, and JavaScript — no framework and no build step. Fonts from Google Fonts (Young Serif, Figtree, JetBrains Mono).

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
